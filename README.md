# 浙江工商大学本科毕业论文（设计）一键排版

为了解决本科毕业生用`.docx`文件写论文要在后期反复修改论文格式的麻烦，于是就有了本项目。本项目的工作原理是先以纯文本（`.qmd`格式，支持R、Python等语言）毕业论文，完事儿后（Quarto自动通过LaTeX）一键生成符合学校版式要求的pdf，彻底跳过繁琐的论文排版阶段。`.qmd`文件除了能写文字，也能嵌入公式、表格和图像等内容，完全包含了毕业论文的各组成要素。除了**毕业论文模板**（正文），本项目还附带了**开题报告模板**。

## 目录结构

```
cover/                两份模板共用的封面（cover.tex 与校徽、校名图）
大论文模板/            正文：大论文模板.qmd、样式 header.tex、参考文献、示例图表
开题报告模板/          开题报告：开题报告模板.qmd、样式 header.tex、手工文献表
模板填写说明.md        每个字段填什么、哪些是示例值、哪些格式有讲究
操作说明.md            怎么编译、出问题怎么查、版式清单
```

## 怎么用

先装好 [Quarto](https://quarto.org)（自带 xelatex 分发即可，需要能排中文的字体）。

用 git：

```bash
git clone <本仓库地址>
cd zjgsu-undergraduate-thesis-template/大论文模板
quarto render 大论文模板.qmd
```

上面的 `<本仓库地址>` 是占位符，仓库建成后会换成真实地址；如果你看到的还是这个占位符，说明 README 尚未更新，直接走下面的 Download ZIP 那条路。

不用 git：在仓库页面点右侧 **Code → Download ZIP**，解压后进 `大论文模板/` 目录，同样执行 `quarto render 大论文模板.qmd`。

编译产物在该目录下的 `output/` 里。开题报告用法相同，把 `大论文模板` 换成 `开题报告模板` 即可。

封面已经预填了一套**虚构的示例信息**：姓名张三、专业金融学、班级金融2301、学号 01234567。这些信息请逐项换成自己的；改哪个键、日期怎么写、学号带前导 0 怎么办，见《模板填写说明.md》。
